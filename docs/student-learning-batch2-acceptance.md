## Changes and boundaries

- The static service worker now bypasses `/api/` before cache lookup. Offline app assets and PIN-encrypted learning storage retain their existing paths.
- The private lesson learning route now rejects adult roles before checking progress or prepared support. Existing student, source and school-access checks remain active.
- External answer/check serializers explicitly project nested citations, visual metadata, history, observations, allowed teaching preferences and previous attempts. Checks send support mode rather than private reasons/evidence IDs. Live setup sends only concept, objective and class level alongside the explicit SDP transport.
- Allowed consented teaching preferences still include selected confidence/study-support values; these are different from private student-model probability/confidence/decision records. Voluntarily supplied question/history/audio and WebRTC SDP can contain identifying details. This work does not claim de-identification.
- `scripts/build-isolated-acceptance.mjs` makes review builds reproducible without reading project env files or replacing normal app outputs.

The optional local-model adapter still serializes more check/personalization context than the hardened external adapter. Its privacy parity and benchmark remain deferred under the user's separate local-model approval gate; this report does not approve enabling it. No local adapter change or model run is included in Batch 2.

Batch 3, training-event collection/export, evaluation harness, speech evaluation, interface refactor and local-model milestones remain deferred. No real-child release or production security certification is claimed.
