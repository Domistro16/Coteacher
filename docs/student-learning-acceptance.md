# Student learning foundation acceptance

This branch contains fictional-data school/authentication, onboarding, private encrypted learning memory, reviewed preparation and live-tutor foundations. It uses transparent support rules; no understanding predictor or model decision ledger is implemented here.

The follow-up Batches 1–2 PR adds the student-model contract/baseline, private decision records, replacement roadmap and expanded access/export/cache/provider-payload checks. Existing service/browser tests are functional plumbing with fictional learners and mocked/synthetic dependencies. They establish no calibrated prediction, real-child safety, learning effectiveness or hosted identity/physical speech suitability.

Improvement-data collection/export, pooled training, neural training and separately gated evaluations remain disabled or deferred. See school-acceptance.md, safety-and-data.md and tests/e2e/README.md for foundation checks and limits.
